INFORME TÉCNICO — PROYECTO ALTRANS (Versión 4.5)
     
     Julio 2026 | Estado general: MVP funcional ~90%
    
    
    
    1. RESUMEN EJECUTIVO
    
     El proyecto Altrans consta de 4 módulos: Dashboard (React SPA), Chatbot (FastAPI), Mensajes WhatsApp y Notificaciones Automáticas (Backup + Mensajes automáticos). El dashboard es una aplicación standalone React + Vite que se conecta directamente a Supabase. El módulo del chatbot está completo (96%) con autenticación, rate limiting, logging persistente, prompts editables y restricción de datos vía v_chatbot_manifiestos. El módulo de notificaciones ahora incluye backup con SendGrid + mensajes automáticos vía WhatsApp (5 plantillas: 4 de pendientes + pago_realizado). El sistema de seguridad por roles (7 roles, RLS, RPCs, audit_log) está implementado correctamente en BD.

     Tiempo estimado para producción: 2-3 semanas (mejoras dashboard + WhatsApp).
